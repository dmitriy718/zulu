# Live Trading Kill Switch Runbook

1. Activate system kill switch first for broad uncertainty.
2. Scope down to tenant, user, ticker, strategy, model, or broker when impact is understood.
3. Confirm live trading is disabled in readiness and execution controls.
4. Confirm pending live orders are reconciled or cancelled through broker-approved flows.
5. Record operator audit notes.
6. Require explicit review before clearing the switch.
